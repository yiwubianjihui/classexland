### 插件改造（ClassExland，当前 v1.0.0.16）

1. **取消插件自带的正式上课弹窗，用原生的**：删 `BellNotificationProvider` 的 `ClassOnNotice` 弹窗分支；
   `BellProfileWriter.Apply()` **不再关闭宿主提醒开关**（`IsClassOnNotificationEnabled` /
   `IsClassOnPreparingNotificationEnabled`），正式上课提示交还宿主原生。
2. **解决部分课节无预备铃时上课时刻显示不佳、多次闪烁**：
   - 原因：无预备铃节（NoPrep）的 `ClassOnNotice` 不切虚拟状态、不发 `VirtualStateChanged`，
     导致界面停留在 `Breaking`、待下课任务不取消、状态对账切回 break；`prep=0` 时 PrepareBell 与
     ClassOnNotice 同刻连弹两次造成闪烁。
   - 修法：`ClassOnNotice` 也置 `OnClass` 并发 `VirtualStateChanged`（至少 NoPrep 节）；
     `SeedStateFromHistory` 同步推导；`Fire()` 对同刻事件去重。
3. **新增「无预备铃」选项 + 动态提前量模式**（用户选「新增模式+两台启用」）：
   - 新增模式：按课间时长自动算提前量——**10 分钟课间提前 2 分钟(120s)、15 分钟提前 3 分钟(180s)、
     无课间不触发预备铃**；保留原固定秒数模式兼容。
   - 两台设备启用这套规则。
4. **无预备铃课节界面也必须切到上课状态**：同 #2 的 ClassOnNotice→OnClass 修复。
5. **广播内容用各科目对应的上课提示**（用户选「读档案科目提示，按科目启用开关」）：
   - 预备铃读 `ClassOnPreparingText`、正式上课读 `ClassOnMaskText`（`Subjects[*].AttachedObjects["08f0d9c3-…"]`）；
   - **该科目 `IsAttachSettingsEnabled=false` 就跳过、回退插件默认文案；绝不改成 true**。
6. **上课状态界面缩放 0.7**：`LayoutConfig.ClassScale` 0.8→0.7（源码默认 + 两台实际配置）。

## 远程站白名单限制（重要）

`upload.php` 的 `CX_ALLOWED_KEYS` 仅允许 `bell.json`/`duty.json`/`activities.json`/`layout.json`。
因此 **`bell-options.json`（`DefaultPrepMode=ByBreak` 与 `BreakPrepRules`）不会通过远程站快照下发**，
只能靠 `19.bat`/`20.bat` 从源包同步到教室电脑。远程快照已下发的四个文件在两台设备上均已核对无误。
